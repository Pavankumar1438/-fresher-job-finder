# AIML Fresher Jobs

A fresher job finder website for AI/ML and CSE students in India.

Live site: https://aimlprojectstarter.live

## Features
- Job and internship listings with search and filters
- Career guides for freshers
- Job alert subscription and contact forms

## Tech stack
- Node.js (single server.js, no npm install needed)
- HTML, CSS, JavaScript
- Hosted on Render, domain from Name.com, DNS and SSL via Cloudflare

## Run locally
node server.js
Then open http://localhost:3000
